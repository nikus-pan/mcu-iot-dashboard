    02 / HARDWARE

    硬體清單與接線

    全部零件皆為市售常見模組，接線僅需 3 條線加一顆上拉電阻。

    #零件規格數量
    1Raspberry Pi Pico WRP2040 + CYW43439 Wi-Fi1
    2DHT22 溫濕度感測器AM2302 · 3.3–5V · 單線1
    3上拉電阻4.7kΩ–10kΩ · 1/4W1
    4麵包板 + 杜邦線400 孔 · 母對公1
    5Micro-USB 電源5V / 1A（或鋰電 + 穩壓）1

    成本約 NT$350–500，可用行動電源供電，適合部署於任何角落。

    03 / ARCHITECTURE

    系統架構

    從感測層到呈現層的完整資料路徑，每一段都可替換或水平擴充。

    1. A

      感測層

      DHT22 以單線協定回傳溫濕度，GP15 讀取，含除錯與超時重試。

      DHT22 · GPIO
    2. B

      邊緣運算

      Pico W 於 MicroPython 計算體感溫度、維持 Wi-Fi 連線與看門狗。

      MicroPython · WDT
    3. C

      傳輸層

      原生 socket 發送 HTTP/1.1 POST，JSON 內含裝置 Token 與讀值。

      HTTP · JSON · TLS
    4. D

      收集層

      FastAPI 端點驗證 Token、寫入時序資料庫，提供查詢 API。

      FastAPI · SQLite
    5. E

      呈現層

      響應式網頁 Dashboard，即時 KPI、趨勢圖與裝置健康狀態。

      HTML · CSS · Canvas

    部署步驟

    1. 刷入韌體：按住 BOOTSEL 插上 USB，將 MicroPython UF2 拖入隨身碟。
    2. 上傳程式：把 main.py、secrets.py 複製到 Pico W 隨身碟。
    3. 接線：依上圖接上 DHT22 與上拉電阻。
    4. 啟動收集端：uvicorn collector:app --host 0.0.0.0 --port 8000。
    5. 開 Dashboard：瀏覽器開啟 index.html 即時監看。
